## 1. 安全目标

1. **令牌即钥匙**：OAuth 令牌与刷新令牌永不落明文、不出本机、不进日志。
2. **数据最小化**：仅申请 `User.Read` + `Mail.Read`（IMAP 兜底另加 `IMAP.AccessAsUser.All`）委托权限；邮件数据仅存本机。
3. **渲染即隔离**：不可信邮件 HTML 永远在无脚本沙箱中渲染。
4. **可审计**：安全相关事件（授权失败、规则被禁用、更新应用）均有结构化日志。

## 2. 威胁建模（STRIDE 摘要）

| 威胁 | 场景 | 缓解 |
| --- | --- | --- |
| Spoofing | 恶意本机程序冒充应用回调截取授权码 | 重定向 URI 使用自定义协议 `mailhelper://` + PKCE（授权码无 verifier 无效）；MSAL 系统浏览器流不经过应用内可注入控件 |
| Tampering | 用户篡改 `rules.builtin.json` 注入恶意正则 | 正则编译/匹配限时 100ms（CLASS-001）防 ReDoS；规则 JSON 加载失败即回退内置默认；发布产物带签名/哈希（08 §4.4） |
| Repudiation | 用户否认执行过改判/清除操作 | `classification_feedback`、`notification_log` 与安全事件日志均含 UTC 时间与操作类型（不含内容本体） |
| Information Disclosure | 令牌/邮件数据被同机其他用户或程序读取 | DPAPI CurrentUser 加密令牌缓存；`%AppData%` 默认仅当前用户可读（SEC-05 ACL 审查）；日志脱敏（§5）；SQLite 不做整机加密但置于用户私有目录（已知限制，见 §8） |
| Denial of Service | 恶意超大邮件/深嵌套 HTML 拖垮进程 | 正文大小上限（5MB 截断，EX-06）；HtmlAgilityPack 解析超时；批处理隔离，单封异常不阻断批次 |
| Elevation of Privilege | 更新通道被劫持推送恶意版本 | Velopack 更新包完整性校验 + 官方发布签名；不提供任意 URL 覆盖更新源 |

## 3. 认证与令牌安全

- OAuth 2.0 Authorization Code + PKCE，系统默认浏览器完成登录（凭据不经过本应用进程）。
- MSAL.NET 令牌缓存启用 `WithTokenCacheCallback` 自定义序列化，写 `%AppData%\MailHelper\tokens\` 前经 **DPAPI（CurrentUser，AdditionalEntropy 加固）** 加密（SEC-01）。
- 静默刷新失败（AUTH-003）即清除内存令牌并降级只读浏览；绝不把刷新令牌写入日志或崩溃转储。
- 登出 = 撤销本地缓存 + 调用 Graph 令牌撤销端点；「清除本地数据」再删物理文件。
- Azure 应用侧：仅委托权限；不申请 `Mail.ReadWrite`（v1.0 无远端写操作）；不启用应用权限；重定向 URI 精确匹配单一协议回调。

## 4. 数据安全

| 数据 | 位置 | 保护 |
| --- | --- | --- |
| 访问/刷新令牌 | tokens 目录（DPAPI） | CurrentUser DPAPI + entropy；非本机该用户不可解 |
| 邮件元数据 | SQLite（WAL） | 用户私有目录 ACL；损坏自动重建 |
| 邮件正文 HTML | bodies 目录文件 | 用户私有目录；LRU 清理；大小上限 |
| 规则/设置 | JSON + settings 表 | 篡改防护见 §2 Tampering |
| 日志 | logs 目录 | 脱敏规范见 §5；保留 14 天自动滚动 |

**红线**：任何代码路径不得将邮件正文、完整令牌、学校账号密码（应用从不经手密码）写入日志、崩溃转储或遥测。本应用**无遥测**（无任何数据外发），崩溃转储仅本地保留。

## 5. 日志与内容脱敏

- 主题：截断 40 字符 + SHA256 前 8 位指纹；发件人：默认仅域名，诊断模式放开至完整地址（提示用户）。
- 正文：任何级别不落日志。
- 错误详情：Graph 错误码保留，`message` 字段白名单过滤后记录。

## 6. 隐私合规（面向香港用户）

### 6.1 PDPO（香港《个人资料（私隐）条例》）六大保障原则对照

| 原则 | 本产品落实 |
| --- | --- |
| 收集目的与方式 | 数据仅为「本地分类管理用户自己的邮箱」而收集；Onboarding 隐私说明（05 §3.1 强制勾选） |
| 使用与保存 | 全部本地处理与保存；用户可随时「清除本地数据」（D-PC-04） |
| 数据质量 | 数据直接来自微软云端，不做二次加工传播 |
| 保存期限 | 正文缓存 LRU 上限；日志 14 天；已删远端邮件记录 90 天可清理 |
| 公开与使用 | 默认无任何外发；**LLM 扩展为唯一例外，须逐次明示同意**（§7） |
| 查阅与改正 | 用户本就持有全部数据（在自己的邮箱与本地库中） |

### 6.2 GDPR 参考（对欧盟交换生同样适用）

数据控制者/处理者角色：本产品为**本地工具，不构成控制者**（不接收个人数据）；若启用 LLM 扩展，则该功能场景下应用行为接近「代表用户向第三方传输」，须显式告知第三方名称与用途。

### 6.3 隐私说明要点（Onboarding 展示文案基础）

1. 我们（开发者）不收集、不上传你的任何邮件数据；分类完全在你的电脑上完成。
2. 应用使用微软官方登录，密码只输入在微软页面；应用仅获得「读取邮箱」授权。
3. 生成分类标注与规则只保存在本机；卸载或点击清除即彻底删除。
4. 如你主动启用「AI 辅助分类」（后续版本）， selected 邮件内容将发送给你配置的 AI 服务商，发送前会逐批征求同意。

## 7. LLM 扩展的隐私边界（V1.1 预留，架构已定）

- 仅对「待确认」队列邮件启用，且**逐次会话级同意**（首次弹窗说明数据将发送至用户自配的 API 服务商；可勾选「记住本选择」）。
- 发送内容：主题 + 正文纯文本（去引文后）；**不发送**令牌、其他邮件、账户标识。
- 提示语要求服务商不用于训练（用户与厂商之间的条款由用户自担）；默认服务商下拉不预填、不做推广。
- 关闭即停：禁用后立即清除 API Key（DPAPI 存储）与临时缓存。

## 8. 已知限制（如实披露）

| 限制 | 说明 | 缓解 |
| --- | --- | --- |
| 本地 SQLite 未整库加密 | 拥有本机管理员权限的攻击者可读取缓存邮件 | 私有目录 ACL + DPAPI 令牌；如需更强保护列入 V2.0（SQLCipher 评估） |
| IMAP 通道无远端删除感知 | 删除感知仅 Graph 通道完整 | 文档明示；本地记录保留可搜索属产品特性 |
| 无遥测导致依赖用户反馈 | 崩溃数据不自动上报 | 诊断模式导出日志包，用户自愿提交 Issue |

## 9. 微软平台政策与商标

- 遵守 [Microsoft Graph 使用条款](https://learn.microsoft.com/legal/microsoft-apis/terms-of-use) 与合理使用：仅用户授权范围内读取、低频轮询、尊重限流。
- 商标：产品名与界面**不得**使用 "Outlook" “Microsoft” 等字样作为产品名或暗示官方关系；描述统一为「适用于 Office 365 学生邮箱的管理工具」；图标不使用微软 logo 变体。
- Azure 应用品牌：提供隐私政策 URL 与服务条款 URL（GitHub Pages 承载本工程书相关章节即可），避免「未验证发布者」警告恶化（单租户自助注册场景由用户完全掌控，无此问题）。

## 10. 安全事件响应

| 阶段 | 动作 |
| --- | --- |
| 准备 | 本文件 + 排障手册（08 §6.2）；GitHub Security Advisories 开启私密漏洞报告 |
| 识别 | 用户报告 / 集成测试契约漂移 / 第三方披露 |
| 遏制 | 受影响版本从更新通道下架（Velopack 撤回 stable 指针）；发布告示 |
| 恢复 | Hotfix（hotfix 分支 → beta 灰度 24h → stable） |
| 复盘 | 48h 内出事后分析（根因/时间线/预防项），记入 ADR 或风险册 |

**假定泄露场景处置**：若签名密钥或 Azure Client Secret 泄露（本产品为公共客户端，无 client secret；仅签名证书风险）→ 吊销证书 → 重新签名 → 更新通道校验指纹。

## 11. 发布前安全检查单（并入 06 §9 G5）

1. SEC-01~06 测试全过（06 §8）。
2. Azure 应用权限最小化复核（无多余 scope）。
3. 依赖漏洞扫描（`dotnet list package --vulnerable`）无高危。
4. 日志抽样人工复查脱敏（开发/测试/诊断三种模式各抽 1 份）。
5. 隐私说明文案与本文件一致（版本联动）。
6. 更新通道完整性验证（篡改 delta 包应被拒绝）。
