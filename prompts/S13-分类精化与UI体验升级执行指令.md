## 二、范围

### A. 规则精化（S13-B）
- **语料驱动**：对 `%AppData%\MailHelper\mailhelper.db` **只读**统计——发件人域 Top20、主题高频词、类别分布、待确认构成；产出「规则差距清单」（哪些发件域无规则覆盖、哪些关键词漏配）。
- **规则包 v2026.10**（`rules.builtin.json`，CityU 特化）：
  - 学校系统域：`cityu.edu.hk` 系（含 `my.cityu.edu.hk` 与各处级子域）；
  - 高频场景关键词（英文为主）：课程（Moodle/Canvas/assignment/quiz/exam timetable/add-drop/course registration）、职业发展（CareER/e-Newsletter/internship/graduate jobs/career fair/CV）、财务（tuition fee/payment due/缴费/学费）、校园事务（library/ITS/SAO/ARRO/graduation/add/drop）、公告（notice/announcement）、订阅营销（newsletter/unsubscribe/promotion/webinar registration）；
  - 每条规则附 `"note"` 字段注明依据（发件域事实/通用词），保持四种标准 Kind（CHG-001 边界不破）；
  - 重要度线索（importanceHint）保守：P0 只给「缴费截止/考试/选退课截止」类，宁漏报 P1 不滥标（02 章附录 B 精神）。
- **版本迁移重分类**（新小特性，测试先行）：
  - Settings 记录已应用规则包版本；启动时发现版本变化→将 `classified_by='rule'` 的邮件置回 pending（confidence 归零、类别清空）→全量重跑分类管线；`classified_by='user'` 不动；完成后记录新版本并在状态栏提示「规则包已更新，重分类 N 封」；
  - 失败安全：迁移在事务内，失败回滚保持旧版本可用（EX-07 精神）。

### B. UI 精美化（S13-C/D）
- **零新增 NuGet 依赖**（总控十一.2 精神）：纯 WPF 资源字典 + 样式 + ControlTemplate 实现精致化。
- **设计令牌**（新建 `DesignTokens.xaml` 合入 App 资源）：色板（主色/背景层级/前景层级/分隔线/语义色 P0-P3/类别色）、字体栈（Segoe UI + 微软雅黑回退）、字号阶、间距阶、圆角阶；所有控件样式只引用令牌，不留魔法数。
- **邮件列表项**：发件人首字母圆形头像（按发件域取类别色）、未读圆点与加粗、主题+预览双行、时间右对齐（今日显时辰/今年显月日/跨年显年）、hover 高亮、选中态清晰。
- **分类栏**：图标+标签+计数徽章一体；选中态主色底；待确认徽章用强调色。
- **阅读窗格**：顶部工具栏（标已读/未读、「改为...」改判菜单、发件人信息头）；正文 WebView2 区域留白与圆角。
- **状态栏/同步**：立即同步按钮态（忙碌转圈/空闲）、状态文本层次。
- **动效克制**：hover/选中 ≤150ms 过渡，无大型动画（性能红线 PERF-01）。
- 深色主题不在本轮（列 S14）；设置页仅被动跟随令牌。
