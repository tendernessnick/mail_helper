## 一、任务与验收

### S14-A 应用图标（G-S14-1）
- 程序化绘制（System.Drawing/GDI+，无设计资源依赖）：圆角方块主色底 + 白色信封 + 橙色角标圆点（呼应「分类+重要度」产品概念），多尺寸 ICO（16/32/48/64/128/256，PNG 压缩条目）。
- 三处接入：①csproj `ApplicationIcon`（exe/任务栏/资源管理器）；②MainWindow.Icon（标题栏 Alt+Tab）；③托盘基础图标（保留未读角标能力）。
- 验收：任务栏/标题栏/托盘三处可见新图标，无白框默认图标残留。

### S14-B 界面修复（G-S14-2）
- **顶栏布局**：DockPanel 改 Grid 三列（左品牌+导航 | 中搜索居中 | 右仅未读+快捷键提示），最大化后搜索区保持视觉居中、不散架。
- **阅读窗格右侧空白**：邮件 HTML（营销模板固定宽表格）靠左渲染导致右侧大片空白——WebView2 注入全局样式：页面浅灰底、正文卡片居中（max-width ~880px）、对称留白；禁用外链策略不变。
- 验收：窗口最大化后阅读窗格内容居中对称；顶栏三段布局清晰。

### S14-C 自定义类别（G-S14-3，CHG-012）
- **模型**：类别从枚举升级为「类别注册表」——内置七类（course/career/admin/finance/announce/subscription/other，ID 不变保证存量数据/规则包/评估集兼容）+ 用户自定义类别（`categories` 表：Id/名称/图标 emoji/颜色/排序/内置标记）。
- **能力**：设置或分类栏内新建/重命名/换色/删除（删除时该类邮件归「其他」，规则随删）；规则编辑与改判的类别下拉列全部类别；分类栏动态渲染。
- **手术范围**（枚举→字符串 ID，受控迁移）：Core 的 MailCategory 引用面（MailMessage/ClassifyRule/ClassificationWrite/SearchQuery/RuleEngine 投票/规则 JSON 解析/评估矩阵）+ UI 转换器/分类栏/DevSeed + 测试。DB `messages.category` 本就是 TEXT（存 ID），**零数据迁移**。
- 红线：SanityTests 的「七值锁定」改为「内置七 ID 锁定」；规则包 v2026.10.1 只用内置 ID；评估集标签兼容。
- 验收：新建类别「实习申请」→ 规则指向它 → 改判可选中 → 分类栏出现并可计数。
