# 工程约定与术语表

> 本页内容原载 README，随产品化改版（v0.5.0）迁入 `docs/`，供参与工程文档编写的成员查阅。

## 统一编号约定

全文档使用以下编号体系，便于交叉引用与需求追溯：

| 前缀 | 含义 | 示例 |
| --- | --- | --- |
| `US-xx` | 用户故事（User Story） | US-01 |
| `UC-xx` | 用例（Use Case） | UC-03 |
| `FR-xx` | 功能需求（Functional Requirement） | FR-02 |
| `NFR-xx` | 非功能需求（Non-Functional Requirement） | NFR-01 |
| `ADR-xx` | 架构决策记录（Architecture Decision Record） | ADR-001 |
| `RISK-xx` | 风险条目（Risk） | RISK-01 |
| `TC-xx` | 测试用例（Test Case） | TC-012 |
| `MOD-xx` | 系统模块（Module） | MOD-02 |
| `CHG-xx` | 变更请求（Change Request） | CHG-013 |

## 术语表

| 术语 | 全称 / 解释 |
| --- | --- |
| O365 | Microsoft Office 365，港校学生邮箱所在的云端服务 |
| Graph | Microsoft Graph API，微软统一的云端数据 REST 接口（v0.5.0 起已移除该通道，术语保留于历史文档） |
| MSAL | Microsoft Authentication Library，微软官方身份认证库（v0.5.0 起已移除） |
| OAuth 2.0 / PKCE | 授权框架及其代码交换扩展（v0.5.0 起不再使用） |
| COM 自动化 | Windows 组件对象模型接口；MailHelper 经它读取本机经典版 Outlook 的已登录邮箱 |
| 经典版 Outlook | Office 桌面版自带的 Outlook 桌面客户端；区别于「新版 Outlook for Windows」与网页版 |
| MVVM | Model-View-ViewModel，WPF 推荐的界面架构模式 |
| PDPO | 香港《个人资料（私隐）条例》 |
| 租户（Tenant） | 学校在微软云中的组织目录；租户策略可能限制第三方应用授权 |
| P0–P3 | 重要程度四级：P0 紧急 / P1 重要 / P2 普通 / P3 低 |
| Velopack | .NET 桌面应用安装与自动更新框架（Setup.exe / 便携包 / 增量更新） |
